# MinifyCode

> Меньше кода. Больше скорости.

MinifyCode — маленький локальный инструмент для аккуратной минификации HTML, CSS и JavaScript. Он работает прямо в браузере: исходники не загружаются на сервер и не покидают устройство.

![MinifyCode preview](assets/favicon.svg)

## Возможности

- три режима: `HTML`, `CSS`, `JS`;
- удаление лишних пробелов, переносов и комментариев;
- защита содержимого `script`, `style`, `pre` и `textarea` в HTML;
- сохранение строк, шаблонных литералов и экранированных символов в JavaScript;
- drag-and-drop файлов `.html`, `.css` и `.js`;
- копирование результата и скачивание минифицированного файла;
- адаптивный интерфейс без внешних CDN и сетевых запросов.

## Запуск

Проект статический. Откройте `index.html` в браузере или запустите любой локальный сервер:

```bash
npx serve .
```

Исходная типизированная логика находится в `src/main.ts`, браузерная сборка без зависимостей — в `src/main.js`. Для максимальной компрессии production JavaScript можно дополнительно прогнать через Terser, но для повседневной локальной минификации инструмент не требует npm-пакетов.
